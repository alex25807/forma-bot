# FORMA — Telegram-бот нутрициолог

Тихий сервис по управлению формой тела. Без жёстких диет, без срывов, без чувства вины.

## Возможности

### Бесплатно
- Расчёт КБЖУ (калории, белки, жиры, углеводы) по параметрам тела
- Одно персональное меню на 3 дня с точными граммовками
- Учёт ограничений по здоровью (гипертония, диабет, аллергии и др.)
- Учёт предпочтений по продуктам (мясо, рыба, крупы, молочка и др.)
- Выбор предпочитаемой кухни (русская, итальянская, греческая и др.)
- Ежедневная поддержка: утренний настрой + вечерний разбор
- Разбор питания за день с AI-рекомендацией
- Отслеживание веса и прогресс (графики)
- Кнопка быстрого входа `🏠 Старт` внизу чата

### Стандарт (299 ₽/мес)
- Всё из бесплатного
- Безлимитные меню на 3 дня с автообновлением
- Рецепты блюд из меню (пошаговые, с полными ингредиентами)
- Мягкий фитнес-модуль (упражнения на 5-10 мин с учётом здоровья)
- Режим «ускорить результат» для клиентов с низкой активностью
- Скачивание меню в файл
- Скачивание рецептов в файл
- Экспорт истории в Excel
- Сохранение графика веса

### Премиум (499 ₽/мес)
- Всё из Стандарт
- Анализ фото еды через AI (GPT-4o vision)
- Персональные рекомендации по фото

### VIP (бесплатно для друзей/родственников)
- Промокод или ручное добавление админом
- Доступ на уровне Стандарт

## Технологии

- **Python 3.11** + **aiogram 3.x** — Telegram Bot API
- **OpenAI API** (gpt-4o-mini, gpt-4o) — генерация меню, рецептов, анализ фото
- **SQLite** (WAL mode) — хранение данных
- **matplotlib** — графики веса
- **openpyxl** — экспорт в Excel
- **aiohttp** — health-check сервер для Railway
- **Telegram Payments** (ЮKassa) — приём оплаты

## Структура проекта

```
app/
├── main.py              # Точка входа, health-check сервер
├── bot.py               # Инициализация бота и роутеров
├── config.py            # Настройки (env-переменные)
├── states.py            # FSM-состояния
├── keyboards.py         # Все inline-клавиатуры

├── handlers/
│   ├── start.py         # /start, информация, подписка
│   ├── calc.py          # КБЖУ-калькулятор, меню, рецепты
│   ├── daily.py         # Ежедневная поддержка, прогресс, фото-анализ
│   ├── fitness.py       # Мягкий фитнес-модуль
│   ├── payments.py      # Telegram Payments (тарифы, оплата)
│   └── admin.py         # Админ-команды, VIP, статистика
└── services/
    ├── database.py      # SQLite: все таблицы и запросы
    ├── llm.py           # OpenAI API (chat + vision) с трекингом расходов
    ├── nutrition.py      # Формула Миффлина-Сан Жеора для КБЖУ
    ├── access.py        # Контроль доступа по тарифам
    ├── charts.py        # Генерация графиков веса (matplotlib)
    └── export.py        # Экспорт истории в Excel
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `OPENAI_API_KEY` | Ключ OpenAI API |
| `ADMIN_ID` | Telegram ID администратора |
| `VIP_CODE` | Промокод для VIP-доступа (по умолчанию `FORMA2026`) |
| `PAYMENT_PROVIDER_TOKEN` | Токен платёжного провайдера (ЮKassa) |
| `STANDARD_PRICE` | Цена Стандарт в копейках (по умолчанию `29900` = 299₽) |
| `PREMIUM_PRICE` | Цена Премиум в копейках (по умолчанию `49900` = 499₽) |

## Команды администратора

| Команда | Описание |
|---|---|
| `/stats` | Статистика: пользователи, тарифы, API-расходы |
| `/reviews` | Просмотр отзывов пользователей |
| `/addvip 123456789` | Добавить пользователя в VIP-список |
| `/viplist` | Список VIP-пользователей |
| `/removevip 123456789` | Удалить из VIP |

## Команды пользователя

| Команда | Описание |
|---|---|
| `/start` | Главное меню |
| `/myid` | Узнать свой Telegram ID |
| `/deletedata` | Удалить все персональные данные (152-ФЗ) |

## Деплой на Railway

1. Создать проект на [railway.app](https://railway.app)
2. Подключить GitHub-репозиторий
3. Добавить переменные окружения в разделе **Variables** сервиса
4. Railway автоматически подхватит `Procfile` и `runtime.txt`
5. Бот запускается в polling-режиме с health-check сервером на `$PORT`

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env  # заполнить переменные
python -m app.main
```

## Go-Live пакет (готовые тексты)

### 1) Короткий оффер (для шапки канала/поста)

> FORMA — тихий AI-нутрициолог в Telegram.  
> Персональное меню на 3 дня, рецепты, мягкий фитнес и поддержка каждый день.  
> Без жёстких диет и срывов. От 299 ₽/мес.

### 2) Onboarding-сообщения (3 шага)

**Сообщение 1 (после /start):**

> Добро пожаловать в FORMA 👋  
> За 2-3 минуты настроим ваш профиль и соберём персональное меню на 3 дня.

**Сообщение 2 (после расчёта КБЖУ):**

> Готово ✅  
> Я учёл(а) ваши параметры, ограничения по здоровью и предпочтения по продуктам.  
> Дальше — соберём практичное меню с граммовками и понятными блюдами.

**Сообщение 3 (после выдачи меню):**

> Меню готово 🔥  
> Вы можете:  
> - получить рецепт любого блюда,  
> - скачать меню,  
> - разобрать день вечером для точной корректировки.  
> Это даёт стабильный результат без перегруза.

### 3) Мини-скрипт продаж (личные сообщения / чат)

**Вариант короткий:**

> Если хотите, подключу вам FORMA Стандарт (299 ₽/мес):  
> безлимитные меню, рецепты, скачивание и фитнес-модуль.  
> Премиум (499 ₽/мес) — плюс анализ фото еды через AI.

**Вариант диагностический:**

> Что сейчас сложнее всего:  
> 1) составлять рацион,  
> 2) держать дисциплину вечером,  
> 3) понимать, почему вес встал?  
>  
> В FORMA это закрывается меню + ежедневным разбором + корректировкой без стресса.

### 4) Чек перед боевым запуском

- В Railway заполнены `BOT_TOKEN`, `OPENAI_API_KEY`, `PAYMENT_PROVIDER_TOKEN`
- Тарифы и цены заданы в `STANDARD_PRICE` / `PREMIUM_PRICE`
- В `@BotFather` подключён платежный провайдер и выдан актуальный токен
- `/start` показывает главное меню, `🧪 Проверить оплату` открывает тарифы
- Успешный платеж активирует подписку и показывает срок действия

## Соответствие 152-ФЗ

- Согласие на обработку ПД запрашивается при первом контакте
- Политика конфиденциальности доступна по кнопке
- Команда `/deletedata` удаляет все данные пользователя
- Middleware блокирует взаимодействие до получения согласия
